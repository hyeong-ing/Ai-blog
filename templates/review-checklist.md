# 게시 전 사용자 검토

대상 본문: / SEO 파일: / 검토일:

- [ ] 핵심 변화가 정확하고 기존 글과 실질적으로 중복되지 않는다.
- [ ] 발표일·출시일·버전·Preview/Beta·요금·OS·권한을 구분했다.
- [ ] 주요 주장에 원문 링크가 있고 fact-check의 미확인 핵심 주장이 없다.
- [ ] 직접 사용하지 않은 경험과 실행하지 않은 테스트를 만들어내지 않았다.
- [ ] 커뮤니티 의견은 개인 의견으로 한정했고 부족한 리뷰 절은 삭제했다.
- [ ] 설치·코드는 공식 자료로 확인했고 실제 실행 여부를 구분했다.
- [ ] 제목·요약·본문이 일치하고 과장·반복·억지 FAQ가 없다.
- [ ] SEO 파일에 필요한 메타데이터가 있고 실제 이미지·게시 내부 링크만 사용했다.
- [ ] 플랫폼에서 지원하는 메타데이터·기술 SEO를 사람이 확인했다.
- [ ] 외부 글·이미지의 인용 및 사용 권한을 검토했다.
- [ ] 비용·권한 등 변동 가능한 정보는 게시 직전 재확인했다.
- [ ] 사용자가 최종 편집하고 직접 게시한다. Codex는 로그인·업로드·게시하지 않는다.

게시 후에만 사용자에게서 실제 URL·게시일을 받아 이력을 갱신한다. 초안과 조사 이력은 보존하며 이동이 필요하면 사용자 확인 후 처리한다.
